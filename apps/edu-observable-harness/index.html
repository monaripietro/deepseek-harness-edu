🎓 DeepSeek Harness EDU

Un LLM da solo riceve testo e produce testo. Un harness prepara il contesto, offre strumenti, registra eventi e orchestra i passaggi. Questa app te lo fa vedere.

Derivazione didattica semplificata di DeepSeek Harness — app statica, solo front-end.

1. Chiave API e provider

2. Il tuo prompt

3. Sezioni del system prompt (aggiunte dall'harness)

4. Tool disponibili (mock)

5. Payload finale — cosa riceve davvero il modello

6. Esegui e osserva

7. Timeline del mini-harness

8. Modalità confronto

Progetto educativo. La chiave API resta nel tuo browser e non viene mai inviata ad alcun server diverso dal provider scelto. Non usare chiavi di produzione.
